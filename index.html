Student Visual Hierarchy Documentation

Document the specific CSS strategies you implemented for at least 5 elements to establish visual hierarchy.

Target Element / Class Hierarchy Principles Applied Implementation Details & Design Rationale
.hero-title (h1) Size & Scale Made the hero title the largest text on the page using 45px and bold font so it becomes the main point and immediately gets the users attention.
background-color: #efddc1; Color and Contrast I used a different background color for the .course-card class to separate the course cards from the rest of the page and make them more noticeable.
font-family: Garamond, serif; Typography Hierarchy I used Garamond as the main font of the website to give the page a consistent and more distinct appearance. I applied it to all elements using the * selector in styles.css.
grid-template-columns: repeat(3, 1fr); Alignment and Grids I used grid-template-columns: repeat(3, 1fr) to create three equal columns for the course cards. The 1fr gives each column an equal share of the available space.
padding: 10px; Negative Space (Whitespace) I used padding to create space between the content and the edges of the course cards so the text and other elements do not look crowded.
display: grid; gap: 20px; Proximity and Grouping, Alignment and Grids I used display: grid to organize the course cards into a structured layout, while gap: 20px creates equal spacing between each card and helps separate the groups of content.
display: flex; justify-content: space-between; Reading Patterns I used flexbox and space-between in the site header to place the logo on the upper-left side and the navigation on the upper-right side. Together with the hero content below, this supports a Z-pattern that guides the user's eyes across the page and toward the main content.
